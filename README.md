# 我在海边打暑假工的那年 · AI 短片工程公开版

一部 93.9 秒的 AI 生成悬疑短片，以及它从零到成片的**完整制作过程、脚本、成本与踩坑记录**。

> **这是虚构作品，不是实拍，也不是真实事件记录。**
> 画面由 AI 视频模型生成，人物形象基于创作者本人照片生成的一致性角色，
> 剪辑、调色、字幕、混音全部在本地用 FFmpeg 完成。

## 三、制作流程

```
① 剧本与分镜          docs/01-故事与剧本.md
        ↓
② 四幕五段式 Prompt    docs/02-四幕提示词.md   → Seedance 2.5 逐段生成 20s
        ↓
③ 逐段验收（抽帧）     人物一致性 / 空间连续 / 屏内质感 / 台词口型
        ↓
④ 剪辑合成            47 个分片 trim → concat → 调色 → 字幕 → 混音 → 编码
        ↓
⑤ 逐帧核验            帧数 / 切点 / 黑场起点 / 字幕边界 / 电平
```

关键一点：**没有用任何图形剪辑软件**。整条片子的剪辑表写在
`scripts/timeline.py` 里，是可读、可 diff、可复现的代码，而不是一个二进制工程文件。

## 五、怎么跑起来

### 1. 环境

- Python 3.8+
- FFmpeg（需在 PATH 中，或在 `config.json` 里写 `ffmpeg_dir`）
- `pip install -r scripts/requirements.txt`

### 2. 配置

```bash
cp config.example.json config.json
```

改这几项：

| 字段 | 说明 |
|---|---|
| `sources.S1..S4` | 四段 20 秒原始生成视频（**不入库，需自备**） |
| `music` | 105 秒配乐 wav |
| `output` | 成片输出路径 |
| `ffmpeg_dir` | ffmpeg 所在目录，留空则用 PATH |
| `font_regular` / `font_bold` | 本机中文字体路径（默认微软雅黑） |

`config.json` 已在 `.gitignore` 中，不会被提交。

### 3. 执行

```bash
cd scripts
python make_subs_v21.py           # 先出 7 个字幕层 PNG
python build_refine_v21_final.py  # 合成成片（约 5–10 分钟，取决于 CPU）
python measure_frames_exact.py    # 逐分片计帧，打印时间轴偏差
```

**关于源视频**：本仓库不提供 `S1–S4`。这四段是按 `docs/02-四幕提示词.md` 用
Seedance 2.5 生成的，含创作者本人的形象一致性角色，不公开。没有源视频时脚本会
报"找不到源视频"并停止，不会产出半成品。

## 七、已知限制（不粉饰）

1. **1080p 是放大的**，原生只有 1280×720。放大用 Lanczos + 轻锐化，不是原生高清。
2. **遥控器造型不统一**：S1/S2 是白色机身，S3/S4 是深灰机身。这是四段分别生成造成的既成事实，后期无法修正。
3. **画面内有品牌字样与 UI 文字**：遥控器机身品牌标、屏内 App 数值、船身中文字、旧机身型号字，全部原样保留，未做遮罩。
4. **眼部特写偏软**：S2 有一段正面特写存在五官漂移，用 2.56 倍裁切放大替代，代价是清晰度下降。
5. **台词与环境声未做人工听验**：只核对过电平（均值 −21.0 dB / 峰值 −1.4 dB），
   **电平正常不等于听感合格**。片中三处对白的清晰度、切点爆音均未经人耳确认。
6. **时间轴有约 0.225 秒（5 帧）的累计偏移**：47 段 concat 的段级占位造成，
   成因已定位到 max(视频段, 音频段)，但仍有 2 帧未完全解释。见 `docs/04`。
7. **未做竖屏适配**：维持 16:9，字幕按竖屏观看放大过字号，但没做竖屏裁切测试。

## 八、成本（结论先说）

- **整个项目**：4 条 Seedance 2.5 视频生成（每段 20 秒，各 1 次）+ 1 条 105 秒 AI 配乐，
  全部走订阅内额度，**现金支出 0 元**。
- **每一轮修改**（v2 / v2.1 / 配音实验）：新增视频生成 **0 条**，现金 **0 元**，
  只用本地 CPU/GPU 做剪辑与编码。
- 因此正确说法是「**现金零支出，额度有消耗**」，不是「完全免费」。

明细与"哪些数字是实测、哪些只是估算"见 `docs/05-成本记录.md`。

## 十一、这份仓库想说明的事

不是"AI 一句话就能出片"。真实过程是：

> 四段 20 秒生成 → 逐段抽帧验收 → 发现人物漂移和遥控器不统一 →
> 用剪辑和裁切绕过去 → 47 个分片手工排时间 → 逐帧核验切点与黑场 →
> 发现一处镜头选错了，整段换掉重来 → 字幕在黑场上的停留时间重新算。

所有失败、返工与没解决的问题都写在 `docs/04` 和 `docs/08` 里，没有只挑成功的部分展示。
