# 四幕提示词（原文）

四段各 20 秒，用同一模型（Seedance 2.5，16:9，单条生成）。
下面是**实际提交给模型的 Prompt 原文**，除删除了参考图的临时 CDN 地址、
画布 ID 与本地文件路径外，一字未改。

> 说明：文中 `<图片N>` 是提交时的参考图序号。四段共用到两类参考：
> ① 场景空镜（港口、岸桥、码头、广场，均不含人脸）；
> ② 一个角色身份参考（由创作者本人照片生成的虚构角色，**图片本身不公开**）。
>
> 为什么每段都要写这么长：模型对"不要出现什么"的遗忘率很高，
> 禁区必须每次重写。这不是 Prompt 玄学，是四段生成里最贵的经验。

## S1《第三天的航拍》（0–20 秒）

**参考图**：5 张（4 张港口空镜 + 1 张角色正脸）
**输出**：1280×720 / 24fps / HEVC / 20.06 秒

### Prompt（原样提交）

【输入资产定位与0秒基准】
<图片1>黄昏港口全景，作为空间与光线基准；<图片2>红色岸桥横梁，作为关键落点；<图片3>集装箱码头纵深，作为前景尺度；<图片4>货轮与堆场，作为工业体量；<图片5>主角正面身份参考，是唯一人脸来源。
0秒基准：黄昏，太阳贴近海平面偏画面右后方，天空自橙红过渡到灰蓝，海面有低角度逆光碎金；空气中有薄雾，远处岸桥成剪影。

【参考主体绑定与生成目标】
<主体1>取自<图片5>：约 20 岁年轻男性，短黑发贴额，单眼皮、鼻梁直、薄唇、下颌线清晰；穿深灰色工装外套，戴深色鸭舌帽，右手握一台带屏幕的白色遥控器。整段只有他一个真人，不出现任何第二个人的脸。
空间绑定：港口尺度取自<图片1><图片3><图片4>，红色岸桥横梁取自<图片2>。写实电影质感，35mm 胶片颗粒，低饱和暖冷对冲，浅景深，稳定构图。

【逐时间段动作、声音与脚本】
0-4 秒，大全景，高位缓慢下摇：黄昏港口，成排橙红色岸桥与集装箱堆场沿海岸线铺开，一艘货轮缓慢横移；海面碎金反射，薄雾在塔架之间流动。环境声：海风、远处吊机钢索吱呀。无对白。
4-8 秒，切中景，45 度侧后方缓推：阿哲站在码头混凝土护岸上，工装外套下摆被海风吹动，鸭舌帽压住额发；他微微仰头看向岸桥高处，右手拇指在遥控器上轻推。人物对白（阿哲，侧脸，低声自语）：{第三天，还是同一个点。} 声音：鞋底摩擦碎石、遥控器推杆咔哒、无人机电机自检的短促蜂鸣。
8-12 秒，切特写，贴屏轻微手持：遥控器屏幕亮起，画面里是岸桥横梁的俯视机位，随他推杆缓慢右移；他指节的汗与屏幕反光同时可见，屏幕亮度照亮他的下半张脸。声音：推杆连续微调、图传电流底噪。无对白。
12-16 秒，切过肩镜头，从他右肩越过去看屏幕，缓慢推近：屏幕画面里，红色横梁尽头站着一个戴红色安全帽的人影，背对镜头，身形与他相近，画面稳定、没有异常抖动。环境声突然压低，只剩风。无对白。
16-20 秒，切中景接仰角：他猛地抬头看向真实的横梁，横梁尽头空无一人，只有夕阳；他迅速低头再看屏幕，屏幕里人影仍在，位置比刚才向前挪了一步。他后退半步，帽檐下的下颌绷紧。人物对白（阿哲，几乎气声）：{谁在上面？} 声音：心跳、风、遥控器在掌心轻微震颤。最后一帧定格在他侧脸与屏幕同框。

【转场与尾态收束】
五镜全部硬切，切点落在动作或视线落点上：下摇末帧接他抬头；推杆仍在进行的动作中切到特写；屏幕画面右移的终点接人影出画；抬头动作接仰角，用同一方向动势承接；结尾以他侧脸与屏幕双焦点定格，为下一段保留"屏幕里还有东西"的悬念。

【全片一致性与禁区】
同一张脸、同一套深灰工装与深色鸭舌帽贯穿始终；港口空间内不出现现代玻璃摩天楼；不出现第二个真人；不出现字幕、画面文字、水印、任何品牌 logo；不出现白天场景；不出现卡通、插画、游戏引擎风格；不出现快速剪辑、跳切、变速；保持 16:9 横画幅电影感，机位稳定不漂移，人物面部不失真。

### 生成后核验

| 检查项 | 结果 |
|---|---|
| 5 个镜头是否成立 | 成立。大全景 → 手柄特写 → 过肩看屏 → 中景接仰角，景别与顺序符合 |
| 空间一致性 | 好。岸桥、护岸、海面、黄昏光贯穿，未串场 |
| 人物一致性 | 中。服装稳定，但人脸只在虚焦背景出现一次，无法确证 |
| 屏幕内容 | **部分失败**。8 秒处屏幕全黑（要求显示岸桥画面） |
| "空无一人" | 未完全实现。远处岸桥上有细小施工人影 |
| 意外元素 | 遥控器上出现清晰的品牌 logo（Prompt 未点名禁止） |

**教训**：没写进禁区的品牌，模型一定会给你补上。从 S2 开始把 logo 明确列进禁区。

## S2《失联信号》（20–40 秒）

**参考图**：3 张（上一段末帧 / 角色正脸 / 码头纵深）
**续接方式**：**末帧作参考图**，不是模型原生续拍
**输出**：1280×720 / 24fps / HEVC / 20.06 秒

### Prompt（原样提交）

【输入资产定位与0秒基准】
<图片1>是上一段视频的最后一帧，作为本段的构图、人物姿态、服装、光线与场景基准：黄昏、逆光、暖灰色天空、人物侧身低头看遥控器、右上方悬着红色龙门吊。
<图片2>是同一角色的面部特征参考，只用于确认五官，不改变<图片1>的发型、帽子和服装。
<图片3>是码头纵深与海面尺度参考，用于第三镜航拍越海的空间关系。
0秒基准：与<图片1>完全一致——同一机位、同一光线、同一天色，人物仍在低头看屏幕，画面保持安静，只有风声。

【参考主体绑定与生成目标】
<主体1>取自<图片1>与<图片2>：同一名年轻男性，黑色棒球帽，深灰色宽松工装外套，面部特征与<图片2>一致，右手握同一台带屏幕的白色遥控器。全段只有他一个真人。
场景绑定<图片1>：大型红色龙门吊、混凝土护岸、海面、暖灰色黄昏天空；不出现任何玻璃摩天楼、不出现城市夜景。
写实电影摄影质感，35mm 颗粒，低饱和暖冷对冲，浅景深；不要夸张科幻特效、不要辉光、不要粒子、不要全息界面。

【逐时间段动作、声音与脚本】
20-25 秒，过肩镜头，从他右肩后方越过去，缓慢推近遥控器屏幕：屏幕里是港口的实时航拍画面，海面与岸桥平稳缓慢移动；推到一半时，画面边缘切进一架没有识别标记的黑色小型无人机，尺寸很小，剪影清楚，飞行姿态稳定；屏幕同时跳出一个简洁的红色警告图标（只有一个图标，不生成任何大段中文或成串文字）。声音：风声逐渐减弱，出现轻微的电子干扰声。无对白。
25-30 秒，硬切人物面部特写，摄影机缓慢向侧面移动：他先是盯着屏幕，眉头微皱，随即迅速抬头看向远处海面上方的天空，下颌线绷紧，眼神从屏幕移向天空。人物对白（阿哲，低声，克制，不夸张）：{那是什么？} 声音：风几乎停止，只剩极低的电流底噪。
30-36 秒，切为无人机第一视角：摄影机高速但平稳地越过港口海面，贴近水面又逐渐抬升，向远处的红色龙门吊靠近；龙门吊的红色钢梁从画面左侧掠过；那架黑色无人机悬停在吊机旁一瞬，随即突然转向，朝一座废弃仓库的方向飞走。画面带真实无人机镜头特征：轻微广角畸变、稳定不抖动、不翻转不甩镜。声音：电机声、低频音乐逐渐收紧。无对白。
36-40 秒，切回人物侧面中近景：他紧盯遥控器屏幕，拇指轻微推动摇杆；摄影机慢慢推近他的眼睛。就在他准备追踪的瞬间，遥控器发出一声尖锐的提示音。人物对白（阿哲，低声，疑惑）：{它在等我？} 声音：尖锐提示音后接一记低频。结尾停在他紧张、疑惑但仍有细微动作的脸上——不是静态定格。

【转场与尾态收束】
四镜全部硬切。第一镜到第二镜用"视线从屏幕抬起"接；第二镜到第三镜用"他看向天空的方向"接主观镜头，方向一致；第三镜到第四镜用"黑机飞向仓库消失"接回他的反应。尾态保持在活动画面：眼睑微动、拇指仍在摇杆上、遥控器屏幕余光映在下巴，便于第三幕直接续接。

【全片一致性与禁区】
同一张脸、同一顶黑色棒球帽、同一件深灰宽松外套、同一台遥控器，外形不发生任何变化；年龄不变；构图与光线延续<图片1>，不换场、不换天。
禁区：不出现任何品牌标识与 logo；不出现第二个真人；不生成大段中文、成串小字或假 UI 文案；不出现手指畸形、多指、手柄变形；不出现画面闪烁、跳帧、撕裂；不做真正静态定格；不加片头、片尾、字幕、水印；不出现夸张科幻特效与未来城市。

### 生成后核验

| 检查项 | 结果 |
|---|---|
| 与 S1 末帧衔接 | **成立**。同为肩后视角、同一天色、同一顶黑帽与深灰外套 |
| 四镜是否落地 | **成立** |
| 异常事件是否可见 | **成立且比预设更好**：黑色无标识无人机同时出现在真实天空与屏幕里，屏内有红色警告标记而非纯文字 |
| 屏幕内容 | **修好了**。S1 的全黑屏问题未复现 |
| 人物一致性 | **未达标**。第 9 秒正面特写五官明显偏移（脸更宽、嘴唇更厚），这一景别下读起来像换了演员 |
| 品牌残留 | logo 仍淡淡出现在遥控器面板上 |

**教训**：正面特写是四段里唯一"翻车"的镜头。修法不是重生成，是**裁掉**——
固定裁窗只留双眼与鼻梁，放大回原尺寸。代价是清晰度下降，见 `docs/04`。

## S3《熟悉的地方》（40–60 秒）

**参考图**：5 张（S2 末帧 / 角色正脸 / 港湾长廊 / 黄昏港区 / 广场逆光）
**输出**：1280×720 / 24fps / HEVC / 20.064 秒 / 481 帧

### Prompt（原样提交）

<图片1>是上一段视频的真实尾帧：黄昏逆光下的年轻男性侧脸，黑色棒球帽压得很低，深灰色宽松外套，右手在画面下缘持一台黑色无人机遥控器，遥控器屏幕里是港口航拍画面，背景是一座红色桁架龙门吊。这一帧只承担人物外观、帽形、外套颜色、遥控器外形与黄昏光比的锚定，不承担本段开场构图与机位。<图片2>是同一角色的正脸身份参考，只锁定脸型、五官比例、年龄感与短发轮廓，不继承它的夜晚球场背景、侧向布光和方形裁切。<图片3>锁定海边空间的整体结构：整排红色岸桥、停泊的白色客船、沿岸白色海滨长廊与绿化、背后城市楼群和青绿色海水。<图片4>锁定天色基准：暖灰色残云压在画面上半部，红色岸桥横向延伸，港区厂房与集装箱堆场在中低部。<图片5>锁定广场空间：开阔铺装地面、玻璃般反光的地面、远处一排摩天楼与暖白天光，行人只以逆光剪影出现。五张图的拍摄角度、原始画幅、屏幕界面文字、水印与平台覆盖层全部剥离，不复刻。

生成同一部悬疑短剧的第三幕：黄昏海边，年轻男性沿石阶下行，用无人机第一视角飞向自己暑假打工的海滨长廊，在屏幕里发现广场中央有一个抬手的人影，与他动作同步却没有遥控器。人物身份、服装、帽子、遥控器始终与<图片1><图片2>一致；空间与光线与<图片3><图片4><图片5>一致。全段没有一处正面近景，人物最高露出到帽檐下的侧脸与眼睛。

0.0-3.0 秒，午后转黄昏的海堤上，他背对镜头站在一段向下的石阶顶端，黑色棒球帽帽檐压低，深灰色宽松外套的下摆在左侧被海风吹起约一拳高，右手单持遥控器垂在身侧，左肩略高。石阶呈浅灰色混凝土，边缘有一道黄色磨损漆线，护栏是不锈钢细杆，下方是白色遮阳棚平台与更远处的红色岸桥。摄影机在他身后约一米半、略偏右，肩扛高度比他的肩线低半头，随他下行产生轻微上下起伏；对焦点始终锁在他的后颈与帽檐。光线来自画面右后的落日，给他外套右肩一道窄暖边，左肩落在冷灰阴影里，空气里有细颗粒。他先迈右脚、脚掌踩实第一级，重心下沉，随后左脚跟上，节奏不快；第 1.4 秒他跨过第三级时外套下摆被气流掀起再落下，第 2.6 秒他越过最后一级踏到平台，脚下传来<鞋底碾过细碎石子的声响>，远处一声<低沉的船笛>拉长。

3.0-7.0 秒，硬切为无人机第一视角：机位贴海面约两米高度，青绿色海面在画面下半部高速后掠，浪尖被切成细碎白线。0.4 秒一艘白色客船的巨大船首从画面右侧压入，船体钢板与缆桩清晰，机身在它上方掠过时轻微向左倾斜，船首把画面右半边遮住再让开；1.8 秒机头自然向右压杆转向，海面从正下方移到画面左下，前方逐渐出现一条白色海滨长廊、成排棕榈、远处红色岸桥与城市楼群；2.4 秒长廊的白色栏杆从画面下缘升起，机身在栏杆上方保持平飞，速度稳定不抖；3.4 秒画面右缘划过一道极细的黑色机臂与半只桨，一闪即出画，不是主体。全程<高频桨叶声>压在最上层，(无配乐)，第 2.0 秒起混入一缕<电子干扰的滋滋声>并持续，风声被压低成垫底。

## 四段共同的写法（可复用的部分）

### 1. 五段式结构

| 段 | 写什么 |
|---|---|
| ① 输入资产定位与 0 秒基准 | 每张参考图各自负责什么；0 秒画面里主体在哪、朝哪、什么姿态 |
| ② 参考主体绑定与生成目标 | 身份只来自身份图，空间只来自场景图，逐项写清"采用什么、剥离什么" |
| ③ 逐时间段动作、声音与脚本 | 按秒写动作链、切点、声音、台词；台词放进 `{}` |
| ④ 转场与尾态 | 每个切点写"前镜结束状态 → 切镜理由 → 后镜开始状态" |
| ⑤ 全片一致性与禁区 | 重复身份锚点；把已知会翻车的东西逐条禁掉 |

### 2. 三条硬规律（四段实测得出）

1. **符号有硬边界**：`{}` 只包逐字台词，`<>` 只包音效，`()` 只包音乐，
   `“”` 只包画面内文字。混用会让模型把说明文字当成台词念出来。
2. **禁区要重写，不能省**。S1 没禁 logo，就出了 logo；S2 禁了，仍然淡淡留着。
   模型对"不要"的遗忘比对"要"更快。
3. **正面近景是不可控项**。四段里唯一翻车的镜头就是 S2 的正面特写。
   后面的 S3、S4 直接写"全段不出现正面长时间特写"，问题不再出现。

### 3. 末帧续接不是原生续拍

S2、S3、S4 都用"上一段真实末帧"作参考图，而不是让模型接着生成。
好处是空间与光线能接住；代价是每一段的 0 秒都必须重新描述这一帧承担什么、
不承担什么（它只锁外观，不锁构图），否则模型会把上一段的构图原样复刻一遍。
