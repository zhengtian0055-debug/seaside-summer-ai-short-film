# 时间线与版本变化

## 一、三个版本

| 版本 | 时长 | 帧数 | 体积 | 状态 |
|---|---|---|---|---|
| v1 完整版 | 106.42s | 2554 | 56,886,364 B | 历史版本，仅文字说明 |
| v2 精修 | 91.917s | 2206 | 45,748,820 B | 历史版本，结尾有错 |
| **v2.1** | **93.916667s** | **2254** | **46,189,262 B** | **展示版** |

三版都是 1920×1080 / H.264 / 24fps / AAC 48kHz 2ch，都由同样的四段源视频剪成。
差别不只在时长，更在**结尾那 9 秒到底用了哪段素材**。

## 二、v1 的六段结构（106.42s）

按"自然节奏"排的初版，六段各 20 秒上下：

| 段 | 时间 | 内容 |
|---|---|---|
| SEG1 | 0.00–20.00 | 暑期工日常，港口大全景 |
| SEG2 | 20.00–39.83 | 异常信号 |
| SEG3 | 39.83–59.83 | 熟悉的地方 |
| SEG4 | 59.83–76.69 | 2025 回忆（用已有素材重剪） |
| SEG5 | 76.69–96.69 | 发现旧无人机 |
| SEG6 | 96.69–106.42 | 反转提问 + 片名黑场 |

问题：106 秒对一条短视频平台的内容偏长，且结尾 10 秒节奏散（从柜前拉到天上，中间空了 3 秒）。

## 三、v2 做了什么（91.917s）

- 全片压到 92 秒内：每段都收紧了入点与出点，47 个分片重排。
- 结尾从 10 秒压到约 7 秒，去掉中间的空镜。
- 字幕字号放大、统一左边距。

**v2 的错**：结尾用了 `S1 5.75–6.50`（白色遥控器满屏、**屏内全黑**）和 `S1 2.10–5.50`
（岸桥下人物）这两段，原以为是"纯仰头镜头"和"纯海景"。

实际逐帧复核 S1 后的真实镜序是：

| S1 时间 | 实际内容 |
|---|---|
| 0.00–2.05 | 港口海面大全景，无人物 |
| 2.10–5.50 | 岸桥下人物侧身/背影 |
| **5.75–6.50** | **白色遥控器满屏、屏内全黑** ← v2 误采 |
| 7.00–约 14.50 | 白色遥控器满屏、屏内有港口画面 |
| 14.40–15.80 | 遥控器屏幕近景收尾 |
| **15.90–19.80** | **人物侧背影连续镜头**（遥控器只占握持小面积，屏朝内） |

所以 v2 的结尾是"一块黑屏的特写"接"岸桥下的背影"，观众看到的是一个没有信息的黑屏占了两秒。

## 四、v2.1 只改了三处

**前提：前五段与 v2 完全一致，一个字没动。**

### 1. 换掉 SEG6 的素材

```
v2:   S1 5.75 黑屏特写  →  S1 2.10 岸桥背影
v2.1: S1 16.60 侧背影 2.90s  →  S1 0.10 纯海面 1.95s  →  渐黑
```

### 2. 把渐黑挂到海面段自己的时间线上

v2 用「画面总长 − 1.40s」倒推渐黑起点。因为总长是 47 个分片堆出来的，
这个倒推值落在哪一段上是不确定的，实际把 1.95 秒的海面段几乎吃光（只剩 0.1 秒）。

v2.1 改成在海面分片的 filter 链里直接写：

```
scale=1280:720:flags=lanczos,setsar=1,fade=t=out:st=0.75:d=1.15
```

无论前面 47 段怎么堆，海面一定先亮着出现、再渐黑。

### 3. 字幕放大与文案改动

- 「一年后 · 同一个傍晚」→「回到现在 · 2026年夏天」
- 统一字号：t1 56px / t2 54 / t3 54 / t7 48 / t4 56 / t5 56 / 片名 96
- 统一左边距 x=110，底部留约 160px 安全边距（1080 高）

## 六、字幕时间窗

| 层 | 文案 | 入 | 出 | 时长 |
|---|---|---|---|---|
| t1 | 2026年7月 · 深圳 · 海边无人机暑期工 | 0.90 | 4.80 | 3.90 |
| t2 | 2025年夏天 · 同一片海 | 53.60 | 56.50 | 2.90 |

| t7 | 回到现在 · 2026年夏天 | 66.10 | 68.20 | 2.10 |

| t6 | 我在海边打暑假工的那年 | 91.50 | 93.25 | 1.75 |

两个刻意设计：

- **t4 → t5 无缝接力**：t4 在 87.45 结束的那一帧已无残字，t5 从 87.45 淡入。
  两条字幕之间没有空档，也没有重叠。
- **t5 跨黑场**：画面 89.542 就全黑了，t5 继续在黑场上停到 90.45。
  声音和字都不跟着画面截断——这是结尾余味的全部来源。

## 七、分片结构（47 片 / 6 组）

| 组 | 片数 | 内容 | 调色档 |
|---|---|---|---|
| SEG1 | 6 | S1 暑期工 | base |
| SEG2 | 9 | S2 异常信号（含 2 片眼部特写） | base / eye |
| SEG3 | 12 | S3 熟悉的地方 | base |
| SEG4 | 9 | 回忆段（S1+S2+S3 重剪） | mem |
| SEG5 | 9 | S4 发现旧机 | s4 |
| SEG6 | 2 | 侧背影 + 纯海面渐黑 | base / sea |

调色档定义见 `scripts/timeline.py` 的 `GRADE`：

```python
"base": "eq=contrast=1.03:brightness=0.008:saturation=1.02",
"mem":  "eq=contrast=1.04:gamma=1.12:brightness=0.030:saturation=0.58,vignette=PI/5.4",
"s4":   "eq=contrast=1.04:brightness=0.045:saturation=1.00",
```

回忆段就是靠 `mem` 这一档（去饱和到 0.58 + 压暗 + 暗角）把 2025 和 2026 切成两个时间层的。
没有做任何"回忆滤镜特效"，就是三个参数。

## 八、为什么没有 v3

v2.1 之后又做过一轮**克隆配音**实验（10 句台词全部换成创作者本人音色的 AI 配音），
技术上跑通了，但音色自然度不满意，最终**不用于发布**。

因此仓库里的展示版是**无配音的原声轨版本**。配音实验的记录留在本地，不进入本仓库。
相关技术事实见 `docs/06-音色克隆教程-计划中.md`（状态：计划中）。
