# 素材来源与授权

一页表把所有素材的来源、权利状态、是否公开说清楚。**不确定的一律标"待确认"，不假装清楚。**

## 一、参考图（未公开）

| 素材 | 来源 | 是否公开 | 说明 |
|---|---|---|---|
| 港口 / 岸桥 / 码头 / 广场空镜（R1–R4 等） | 创作者本人实地拍摄的私人相册 | ❌ 不公开 | 仅作生成参考，不入库 |
| 角色身份参考（C1 正脸） | 创作者本人照片 | ❌ 不公开 | 是四段生成里唯一的人脸来源 |
| 上一段末帧（T0 系列） | 由本项目的 AI 生成片段导出 | ❌ 不公开 | 含本人形象 |

**关于私人相册**：项目早期评估过一批相册素材，最终**全部排除**，
没有使用任何含第三方（家人、路人）面部识别的照片。
本仓库不含这些照片，也不提供它们的任何路径。

## 二、生成片段（未公开）

| 素材 | 生成方式 | 是否公开 |
|---|---|---|
| `S1_v1.mp4` ~ `S4_v1.mp4`（4 条 × 20 秒） | Seedance 2.5，按 `docs/02` 的 Prompt 生成 | ❌ 不公开 |

不公开的原因：画面里是**基于创作者本人形象生成的角色**，逐帧看就是这个人的脸。
把它作为"素材"发出去，等于公开分发一组本人肖像。

想复现的读者，可以用 `docs/02-四幕提示词.md` 里的 Prompt 配自己的场景与人像去生成。

## 三、配乐

| 项 | 内容 |
|---|---|
| 文件名（本地） | 105 秒氛围配乐 wav |
| 来源 | AI 音频生成工具产出 |
| 计费 | 订阅内额度 |
| 是否公开 | ❌ 不随仓库分发，仅存在于成片音轨中 |
| 授权状态 | **待确认，见下方说明** |

**待确认项**：使用哪个音频生成工具、该工具的服务条款是否允许把生成结果用于公开作品的配乐，
这件事需要在工具条款里核对并记录。**在补齐之前，本仓库不声称该配乐可被自由复用。**

## 四、字体

| 项 | 内容 |
|---|---|
| 字体 | 微软雅黑 / 微软雅黑 Bold |
| 授权 | 微软系统字体授权，**不可再分发** |
| 是否公开 | ❌ 仓库**不含**字体文件 |

脚本只调用**本机系统字体路径**（`config.json` 的 `font_regular` / `font_bold`），
不在仓库里存字体。用别的机器跑，需要自己指定本机可用的中文字体。

这也是为什么 `config.example.json` 里字体是路径而不是字体文件——
把字体放进来就是侵权。

## 六、明确排除的内容

整理公开版时，下列内容被主动排除，**没有上传，也没有放进任何提交**：

| 排除项 | 原因 |
|---|---|
| 逐帧测量缓存（数百个临时 mp4 与 log） | 中间的脚手架，没有展示价值，体积大 |
| 模型权重（`.pth` / `.ckpt` / `.safetensors`） | 生物特征衍生文件，不可分发 |
| 个人原始录音与音色数据集 | 同上 |
| 账号凭据、令牌、Cookie | 安全 |
| 私人聊天记录、第三方个人信息 | 隐私 |
| 含第三方面部的照片 | 肖像权 |
| 旧版成片 v1 / v2 的完整文件 | 体积大，已在 `docs/03` 用文字说明变化 |
| 克隆配音版成片 | 音色不满意，不发布 |

## 七、需要作者本人确认的项目

下面几项**只有作者能拍板**，在确认之前不写进公开仓库的正文：

1. **配乐生成工具与条款** —— 决定 `docs/05` 与本节能否写"可公开使用"。
2. **画面内品牌字样是否原样描述** —— 片中遥控器机身、船体、屏内 UI 有品牌字与中文字，
   本仓库选择"如实描述其存在、不展示其画面"。是否保留这些品牌名的文字描述需确认。
3. **是否公开"做过克隆配音但未采用"这件事** —— 目前 `README` 第九节与 `docs/03` 末尾
   都写了这件事。如果作者希望完全不提及，需要删掉这两处。
4. **成片走 Release 还是不入库** —— 目前按 Release 附件处理。

## 八、结论

本仓库能公开的部分是：**代码、流程文档、提示词、复盘、成本记录、核验截图（不含人脸）**。

不能公开的部分是：**人脸、声音、原始素材、模型权重、大体积视频**。

这条界线不是技术限制，是**这四类东西一旦出去就收不回来**。
